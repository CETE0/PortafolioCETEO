# Pícaro meshes

Original character assets by Mateo Cereceda, reused from the author's Godot `dither` project (`Recursos Imagen/PICARO`). All rights reserved; these are not third-party open-source models.

`Base.obj`, `Caja.obj` and `Tubo.obj` retain their original geometry, coordinate system and pivots. The renderer assigns its own neutral materials, so it does not fetch the OBJ files' referenced MTL files.

The native homepage and isolated renderer study both use these assets. Animation provenance and reference-comparison limitations are documented in `docs/equilibrio-renderer-study.md`; physical landing behavior and verification are in `docs/equilibrio-landing.md` in the repository.
